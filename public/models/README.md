# Bundled 3D Aircraft Model Attribution

These model files are copied from the World Select Golden Donor (`Siechelmond/ws-donor`).
They are third-party visual assets and are not covered by the repository's source-code license.
The donor documents all of the following as CC BY 4.0 assets.

- `airplane.glb` — “boeing 747” by zairiq-123 (Sketchfab), substantially optimized and prepared for the donor runtime.
- `jet.glb` — “Private Jet” by Nick the Name (Sketchfab), repackaged for the donor's military-flight visualization.
- `bell206.glb` — “Bell 206 JetRanger” by terran4627 (Sketchfab), optimized and baked to real-world meter scale.
- `c172.glb` — “Cessna 172” by e737 (Sketchfab), optimized and baked to real-world meter scale.
- `b789.glb` — “Boeing 787-9” by Nobilis 2 (Sketchfab), optimized and baked to real-world meter scale.
- `atr72.glb` — “ATR 72 - 600” by Oyan3D (Sketchfab), optimized and baked to real-world meter scale.
